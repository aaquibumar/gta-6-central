Important hosting limitation: GitHub Pages is static hosting, so this dashboard has no server-side login and cannot publish changes directly. It saves edits in this browser only. To publish to everyone, export content.json, replace data/content.json in your GitHub repository, and commit the change. Do not enter secrets or passwords here.

Publishing checklist

1. Export content.json from this page. 2. In GitHub, replace the file at data/content.json. 3. Commit to the default branch. 4. GitHub Pages redeploys automatically. Scheduled Newswire coverage updates are handled by the included GitHub Actions workflow. The workflow uses the repository’s built-in token and needs Actions read/write permissions.

For a real multi-user admin panel with accounts, roles and direct publishing, add a backend or CMS later. A password placed in a static HTML/JavaScript file is not secure.
